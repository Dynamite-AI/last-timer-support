Last Timer Pro est une application de minuteurs payante sans publicité. Elle ne contient aucun SDK publicitaire, de consentement publicitaire ou d’achat intégré et ne nécessite aucun achat supplémentaire.

Minuteurs illimités, historique et notes, favoris, archives, pause, notifications anticipées et répétées, règles par jour et plage horaire, widgets, raccourcis, thèmes et vibrations.

Exportez depuis Informations dans Last Timer, puis choisissez le fichier dans Transfert de données dans Pro. L’importation nécessite une application sans minuteurs ni historique. Les notifications importées sont désactivées; les données et notifications d’origine restent intactes. Vérifiez les deux applications avant de les activer pour éviter les doublons.
