Revisa esta información antes de comunicar un problema con las notificaciones o la restauración de compras.

No llegan las notificaciones

En los ajustes del iPhone, comprueba que Last Timer tenga permiso para enviar notificaciones y revisa si el modo Concentración o el modo de bajo consumo afectan la entrega. El sistema operativo puede retrasar u omitir notificaciones.

Restaurar una compra de Pro

Inicia sesión en la tienda con la misma cuenta de Apple o Google utilizada para comprar. Abre Last Timer Pro en la aplicación y selecciona Restaurar compra.

Faltan temporizadores después de cambiar de dispositivo

Los temporizadores y el historial se guardan en el dispositivo. La versión actual no ofrece sincronización entre dispositivos ni copia de seguridad en la nube.

Contacto e informes de errores

Escribe a dynamiteai.support@gmail.com e indica el modelo del dispositivo, la versión de iOS o Android, los pasos para reproducir el problema y el resultado esperado.

No envíes contraseñas, códigos de verificación, identificadores oficiales, números de tarjeta de crédito ni datos bancarios. Para consultas sobre compras, no envíes el identificador de compra a menos que te lo pidamos.

Aviso importante

La aplicación no es un dispositivo médico, servicio de emergencias, sistema de gestión de medicamentos ni sistema de seguridad. Si necesitas notificaciones garantizadas, utiliza un método específico para ello.
