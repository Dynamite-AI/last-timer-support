Last Timer Pro — платное приложение таймеров без рекламы. Оно не содержит SDK рекламы, рекламного согласия или встроенных покупок и не требует дополнительных покупок.

Неограниченные таймеры, история и заметки, избранное, архив, пауза, предварительные и повторные уведомления, правила по дням и времени, виджеты, команды, темы и тактильные настройки.

Экспортируйте из раздела информации в Last Timer и выберите файл в переносе данных Pro. Импорт возможен только без таймеров и истории. Импортированные уведомления отключены; исходные данные и уведомления сохраняются. Проверьте оба приложения перед включением, чтобы избежать дублей.
